1. DESIGN TOKENS

Design tokens are the atomic values that power the entire system. All values use a semantic naming convention.
1.1 Token Architecture

Token: --fs-{category}-{property}-{variant}-{state}
Example: --fs-color-surface-primary-hover

| Category   | Prefix              | Description                                 |
| ---------- | ------------------- | ------------------------------------------- |
| Color      | `--fs-color-*`      | All color values                            |
| Typography | `--fs-type-*`       | Font families, sizes, weights, line-heights |
| Spacing    | `--fs-space-*`      | Margin, padding, gap values                 |
| Elevation  | `--fs-elevation-*`  | Shadows, backdrop filters                   |
| Border     | `--fs-border-*`     | Width, radius, style                        |
| Motion     | `--fs-motion-*`     | Durations, easings, delays                  |
| Breakpoint | `--fs-breakpoint-*` | Responsive widths                           |

12. ACCESSIBILITY
12.1 Color Contrast
All text on backgrounds must meet WCAG AA (4.5:1 for normal text, 3:1 for large text)
Interactive elements must have visible focus indicators
Never rely on color alone to convey meaning — always pair with icons or text labels
12.2 Focus Management
css
:focus-visible {
  outline: 2px solid var(--fs-color-focus);
  outline-offset: 2px;
  border-radius: var(--fs-radius-sm);
}

/* Remove default outline, replace with custom */
:focus:not(:focus-visible) {
  outline: none;
}
12.3 Motion Preferences
css
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
12.4 Screen Reader Support
All icons must have aria-label or be hidden with aria-hidden="true" + descriptive text
Modal traps focus and announces via aria-live="polite"
Progress rings use role="progressbar" with aria-valuenow
Drag-and-drop provides keyboard alternatives
